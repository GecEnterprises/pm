# pm 0.0.5

- **Ticket search** — a search icon in the Tickets list header filters by
  title/ID as you type, narrowing the list and jumping the selection to the
  first match; `Ctrl+F` opens and focuses it directly.
- **Ticket history** — every field edit (title, status, priority, labels,
  assignee, description) and comment is now recorded on the ticket, with a
  human-readable "who did what, when" trail shown in its detail view.
- **Undo/redo in text fields** — `Ctrl+Z` / `Ctrl+Shift+Z` (or `Ctrl+Y`) now
  work in ticket titles, descriptions, and comments, coalescing a burst of
  typing into a single undo step.
- Fixed a `pm --setup` flake: a leftover Enter keystroke from the
  `irm | iex` install command could get silently consumed as the answer to
  the first y/n prompt instead of waiting for yours.
- Commit history now opens by default.
- Internal: began vendoring `fremantle`, a domain-free `gpui` component
  crate that `pm-ui` builds on, with a proper theme system as the first
  piece to move over.
