# pm 0.0.4

- **Ticket store location** — first time you open Tickets, pm asks whether to
  keep tickets in-repo (`.pm/`, shared via git) or in `~/.pm` (local only),
  instead of always defaulting to one.
- **Status bar "Acting as"** — a user chip in the footer shows who you're
  acting as, defaulting to your git username; click it to override.
- Fixed overlapping dropdowns: the user popover, ticket filter, and status
  picker now close each other when opened, so only one is ever up at a time.
- Fixed a stale comment bug: starting a new ticket now clears the comment
  box, so a draft comment from a previously viewed ticket no longer leaks
  into the next one posted.
- Diff view scrolls a little past the last line instead of stopping flush
  with the bottom.
- Fixed a title-bar re-entrancy abort when the window title changed during
  render.
