# pm 0.0.3

- **Watchjump** — a footer toggle (also View → Watchjump). While on, saving a
  file in your editor makes pm open that file's diff and scroll to the first
  changed line. Ignores branch switches / commits and gitignored paths.
- **Recent projects** — File → Open Recent Projects (and the "Nothing opened"
  screen) list the last projects you had open; picking one loads it in place.
- `Ctrl+Tab` / `Ctrl+Shift+Tab` cycle Summary → File-to-File → Tickets.
- `Esc` closes the open menu, then the About dialog.
- Long window titles are ellipsised instead of running under the menu bar.
- **`pm --setup` fix** — it no longer leaves Windows Terminal / PowerShell in a
  broken state after install (dropped the TUI prompt library).
