# pm 0.0.2

CLI reshape and a proper Windows installer (PM-5).

- The CLI is now flags, not subcommands: `pm` opens with no project (a
  "Nothing opened" screen with an Open-a-project button; the view switcher is
  disabled until you pick one), `pm .` / `pm <path>` open the diff GUI,
  `pm --mcp` runs the MCP server, `pm --update` self-updates.
- `pm --setup` — registers pm in the Windows registry (App Paths + an uninstall
  entry, so pm shows up in "Installed apps" / BCUninstaller), optionally adds a
  Start Menu shortcut, and wires pm's MCP server into Claude Code (`claude mcp
  add`, falling back to editing `~/.claude.json`). `install.ps1` runs it after
  install; `pm --uninstall` reverses everything.
