# pm 0.0.1

First tagged build.

- Side-by-side diff viewer with syntax highlighting, working-tree and per-commit
  targets, and a commit-history pane.
- In-repo ticket tracker (`.pm/pm.json5`): create, comment, set status, filter,
  line anchors.
- `pm mcp` — a Model Context Protocol server over the ticket store.
- Whole-window zoom, resizable panes, custom client-side-decorated chrome.
- Windows install script + `pm update` self-updater.
